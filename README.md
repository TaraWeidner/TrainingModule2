# Inclusive Health Training Module 2

Interactive employee training for **Module 2: Clinical Workflows & Skills**.

## Courses

- 2.1 Clinical Foundations
- 2.2 Diagnostics & Procedures
- 2.3 Gender-Affirming Care Workflows
- 2.4 Behavioral Health Crisis Workflow
- 2.5 Sexual Health Testing Workflows
- 2.6 Chronic Disease Management
- 2.7 Emergency & Acute Care Triage
- 2.8 Office-Based Procedures & Clinical Prep

## Training features

- Learner profiles and role selection
- All course buttons labeled **Begin Module**
- Interactive lesson navigation
- Role-specific guidance and competency checklists
- Final assessments with an 80% passing score
- Unlimited assessment retakes with best-score tracking
- Learner attestation and printable completion certificates
- Browser-local progress storage
- CSV training-record export
- Responsive desktop/mobile layout

## GitHub Pages deployment

This project is designed to deploy directly from the repository root.

1. Open **Settings → Pages**.
2. Set **Source** to **Deploy from a branch**.
3. Select **main**.
4. Select **/(root)**.
5. Save and allow GitHub Pages to publish the site.

## Tracking note

Training records currently live in the learner's browser local storage. Export the CSV record for personnel-file documentation. A centralized employee-record backend can be added later without rebuilding the course content.

## Content governance

Course version: **2026.09.02**.

The clinical curriculum in this repository was structured from the source training packets supplied by Inclusive Health. Clinical leadership should review and approve content before treating it as required production training. Keep PHI and other patient-identifying information out of this public repository.
